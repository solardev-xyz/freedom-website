Everything the next internet needs, in one browser

Sites no one can take down

Freedom runs its own Swarm and IPFS nodes. Pages come straight from the network, not from a company's server.

Names you actually own

Type an address like freedombrowser.eth and go. Decentralized names just open, no extension needed.

A wallet built in

Hold, send and sign from the browser itself. Your keys never leave your device, and hardware wallets are supported.

Publish without permission

Put a website or file on the network straight from the browser. No hosting company, no one who can take it down.

An agent that builds with you

Freedom Agent researches, reads pages and steers the browser. Ask for a website and it builds it, publishes it to Swarm and registers a .eth name. Anything that spends or publishes waits for your approval.

No gateway in between

Links to eth.limo, eth.link and bzz.link pages can open straight from Swarm and IPFS, one click from the address bar or by default.

The agent is off by default and works with the model you choose, including local ones through Ollama. Read about Freedom Agent →

Developers

Build on Freedom

Your user’s node is the backend. Pages publish, read, sign and message through the browser’s own Swarm and Radicle nodes — no servers, gateways or API keys.

Ship the app on bzz:// or an ENS name. State lives in Swarm feeds; collaboration goes through Radicle. Consent is wallet-grade: the user connects an origin once, then approves publish and sign prompts.
